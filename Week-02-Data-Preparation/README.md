
# Week 02 - Machine Learning Data Preparation

## Dataset
**Name:** Student Performance Factors

**Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors)

**Target:** Exam_Score

**Problem Type:** Regression

## Project Summary
This assignment focuses on preparing student performance data for machine learning.
The dataset is explored and cleaned, and two new features are engineered.
Numerical features are scaled and categorical features are encoded.
The final output consists of training and testing datasets ready for modeling.

## How to Run
1. Download the notebook from this folder.
2. Open it in Kaggle or Jupyter Notebook.
3. Download the dataset from the Kaggle source linked above.
4. Attach the dataset in Kaggle, or update the CSV path for local use.
5. Install dependencies from requirements.txt.
6. Run all notebook cells in order.
